# Feature Analysis – RK's Waste Management

## Core Features

| Requirement | Feature | Why Is This Feature Important? | Stakeholder Need | Priority |
|---|---|---|---|---|
| FR1 | Waste Sorting Guide | Helps users understand which type of waste belongs in each category. | Households need clear disposal information. | High |
| FR2 | Recycling Information | Explains what can and cannot be recycled. | Users need clear recycling guidance. | High |
| FR3 | Correct Disposal Guide | Helps users understand how to dispose of different waste correctly. | Residents need easy disposal instructions. | High |
| FR4 | Simple Website Navigation | Helps users quickly find waste and recycling information. | Users need an easy-to-use website. | High |
| FR5 | Contact and Support Information | Gives users access to extra help or information. | Users may need further support. | Medium |

## Feature Priorities

### High Priority
- Waste Sorting Guide
- Recycling Information
- Correct Disposal Guide
- Simple Website Navigation

### Medium Priority
- Contact and Support Information

## Stakeholder Connection

These features support the needs of Australian residents and households by providing clear and simple waste management information. They also support local councils and waste management organisations by encouraging correct waste disposal and recycling practices.
