# RK's Waste Management

A student-developed frontend prototype. The website helps Australian households find simple, easy-to-read guidance for recycling and responsible disposal of common waste items.

## Team RK

- Team leader: Ram
- Members: Pujan, Kundan, Prasim, Rajesh and Raman

## Core features

- Waste Finder: searches a prototype database and suggests a waste category.
- Waste category and recycling guidance.
- Responsive navigation for desktop and mobile.
- Frequently asked questions and a validated prototype contact form.

## Project files

- `index.html` — website content and structure
- `style.css` — responsive styling
- `script.js` — interactive menu, Waste Finder, FAQ and contact form
- `stakeholder-analysis.md` — stakeholder evidence
- `requirements.md` — functional and non-functional requirements
- `feature-analysis.md` — feature priorities
- `homepage-planning.md` — homepage plan

## Run locally

Open `index.html` in a browser, or use the **Live Server** extension in VS Code.
