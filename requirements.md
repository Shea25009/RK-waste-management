Requirements Portfolio

Functional Requirements

The website shall display different waste categories.
The website shall provide recycling information.
The website shall provide correct waste disposal guidance.
Users shall be able to navigate between website pages.
The website shall provide contact or support information.
Non-Functional Requirements

The website should be easy to use.
The website should work on desktop, tablet and mobile devices.
Information should be clear and easy to read.
The website should use a consistent layout.
The website should work on modern web browsers.
